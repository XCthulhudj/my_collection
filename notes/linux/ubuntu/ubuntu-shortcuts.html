Ubuntu 桌面快捷键速查

GNOME 默认设置 · 窗口 / 工作区 / 终端 / 文件管理器 / 截图 · 适合嵌入式与 C/C++ 开发日常

1. 窗口管理

快捷键功能
Super（Win）打开活动概览 / 应用搜索
Alt + Tab切换窗口
Alt + F4关闭当前窗口
Super + ↑最大化窗口
Super + ↓还原 / 最小化窗口
Super + ←窗口靠左排列
Super + →窗口靠右排列
Super + D显示桌面
Super + L锁定屏幕
Ctrl + Alt + Tab切换系统界面元素

2. 工作区管理

快捷键功能
Ctrl + Alt + ↑切换到上方工作区
Ctrl + Alt + ↓切换到下方工作区
Super + PageUp切换到上一个工作区
Super + PageDown切换到下一个工作区
Shift + Super + PageUp将窗口移动到上一个工作区
Shift + Super + PageDown将窗口移动到下一个工作区

3. 终端（开发常用）

快捷键功能
Ctrl + Alt + T打开终端
Ctrl + Shift + T新建终端标签页
Ctrl + Shift + W关闭当前标签页
Ctrl + Shift + C复制
Ctrl + Shift + V粘贴
Ctrl + L清空终端显示区域
Ctrl + C中断当前命令
Ctrl + D退出当前 Shell / 发送 EOF
Tab自动补全
↑ / ↓浏览历史命令
终端里 Ctrl + C 是"中断命令"，复制 / 粘贴请用 Ctrl + Shift + C / Ctrl + Shift + V。

4. 文件管理器

快捷键功能
Ctrl + N新建窗口
Ctrl + T新建标签页
Ctrl + L输入路径
Ctrl + H显示 / 隐藏隐藏文件
Ctrl + C复制
Ctrl + X剪切
Ctrl + V粘贴
F2重命名
Delete移至回收站
Shift + Delete永久删除

5. 截图

快捷键功能
PrtSc打开截图界面（视版本而定）
Alt + PrtSc截取当前窗口（部分版本）
Shift + PrtSc截取指定区域（部分版本）

6. 最值得先记住的

快捷键功能
Ctrl + Alt + T快速打开终端
Ctrl + Shift + T终端新建标签页
Ctrl + L文件管理器里快速输入路径
Ctrl + H显示隐藏文件
Alt + Tab切换程序
Super + ← / →左右分屏
Ctrl + C终止终端程序
补充：Super 就是键盘上的 Windows 徽标键。不同 Ubuntu 版本、GNOME 配置和键盘布局可能存在差异，可在「设置 → 键盘 → 查看和自定义快捷键」中查看或修改。
