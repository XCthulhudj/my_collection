# Windows 使用技巧

[← 返回笔记索引](../README.md)

记录日常操作里省时间的小技巧，先收一条最常用的：**在某个文件夹里直接打开命令行**。

## 1. 在当前文件夹打开 CMD（Alt + D 法）

步骤：

1. 用资源管理器打开目标文件夹；
2. 按 **`Alt + D`**，光标跳到地址栏（等同于 `Ctrl + L`）；
3. 输入 `cmd`，回车；
4. 弹出的命令提示符**工作目录就是这个文件夹**。

验证一下确实进去了：

```cmd
echo %cd%
dir
```

> `Alt + D` 的作用是"聚焦地址栏"，浏览器里也一样（Chrome / Edge 都能用）。地址栏除了打路径，还能直接当命令行用。

## 2. 同一招的其他变体

地址栏里换成别的命令，就能开不同的终端，工作目录同样是当前文件夹：

| 地址栏输入 | 打开什么 | 说明 |
|---|---|---|
| `cmd` | 命令提示符 | 最通用，任何 Windows 都有 |
| `powershell` | Windows PowerShell 5.1 | 支持脚本，见 [PowerShell 笔记](../powershell/README.md) |
| `pwsh` | PowerShell 7+ | 装了 PowerShell 7 才有，语法更现代 |
| `wt` | Windows Terminal | 装了 Windows Terminal 才有，可开多标签 |
| `bash` | Git Bash /WSL | 装了 Git for Windows 或 WSL 且 `bash` 在 PATH 里才行 |

## 3. 其他几种打开方式

| 方式 | 操作 | 备注 |
|---|---|---|
| 地址栏（最快） | `Alt + D` → `cmd` → 回车 | 不离开当前窗口 |
| 右键菜单 | 文件夹空白处 **Shift + 右键** → "在此处打开 PowerShell 窗口" / "在终端中打开" | 名字随系统版本变化 |
| 菜单栏 | 资源管理器菜单「文件 → 打开 Windows PowerShell」 | Win11 里在「···」里 |
| 命令里反向操作 | CMD 里执行 `start .` 或 `explorer .` | 用资源管理器打开当前目录 |
| 复制路径 | `Ctrl + L` 选中路径 → `Ctrl + C` | 粘贴到终端里再 `cd` |

## 4. Win + R 里也能用

按 `Win + R` 打开"运行"，输入：

| 输入 | 效果 |
|---|---|
| `cmd` | 打开命令行（工作目录是用户目录） |
| `powershell` | 打开 PowerShell |
| `.` | 打开当前用户目录 |
| `%temp%` | 打开临时目录 |
| `control` | 打开控制面板 |

注意：Win+R 打开的命令行默认在**用户主目录**，不是你想的那个文件夹，所以"在某个文件夹里开终端"还是用第 1 节的地址栏法。

## 5. 常见问题

| 现象 | 说明 |
|---|---|
| 输了 `cmd` 回车没反应 | 检查有没有被输入法挡住；地址栏里别带前导空格 |
| 打开的窗口一闪就没了 | 一般是命令写错（比如打成了 `cmd /c` 之类），或路径指向了 exe；直接输 `cmd` 不会闪退 |
| 需要管理员权限 | 地址栏法开的是普通权限；要用管理员就 `Win + X` → "终端(管理员)" |
| 中文路径 | 能正常打开，但 CMD 里中文可能显示乱码，`chcp 65001` 切 UTF-8 |
| 想在 VS Code 里直接开 | 文件夹里空白处右键「在终端中打开」，或 VS Code 里 `` Ctrl + ` `` |

## 6. 一句话记住

**`Alt + D` → `cmd` → 回车**：不用复制路径、不用在终端里 `cd`，一步到当前目录。
