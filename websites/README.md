# 网站收藏

收录日常使用的网站，按使用场景分成 6 类。每个类别一个文件，新增网站时放进对应文件，并在下面的清单里登记。

## 分类清单

| 类别 | 文件 | 收录范围 | 条目 |
|---|---|---|---|
| 硬件设计与开源硬件 | [hardware.md](hardware.md) | 开源电子项目、原理图/PCB、单片机与嵌入式开发参考 | 1 |
| 机械模型与三维设计 | [mechanical.md](mechanical.md) | CAD 模型库、机械零件与装配体、建模参考 | 1 |
| 软件与工具资源 | [software.md](software.md) | Windows 软件、科研工具、开发工具与资源站点 | 1 |
| 代码托管与协作 | [code.md](code.md) | Git 托管平台、开源项目、Issue / PR 协作 | 2 |
| AI 助手 | [ai.md](ai.md) | 对话式 AI、代码辅助、资料整理 | 2 |
| 技术学习与社区 | [community.md](community.md) | 技术博客、教程、问答社区 | 1 |

## 记录约定

1. 每个网站至少写清 **名称、链接、主要用途**，用途写具体一点，方便日后回忆为什么要收藏。
2. 新增条目后同步更新上表的「条目」数。
3. 软件下载类网站要注明来源与授权风险，优先从官网获取。
4. 链接优先用 `<https://...>` 形式，避免被某些编辑器误加转义。
